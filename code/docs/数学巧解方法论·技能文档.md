## 2. 方法卡

### M1 复数法证几何（托勒密模板）

**内核**：把平面点看成复数后，几何等式变成代数恒等式，"取模 + 三角不等式"一步把等式升级成不等式，且取等条件自动读出。
**流程**（托勒密为例）：
1. 设 `A=0, AB=z₁, AC=z₂, AD=z₃`，各边长 = 复数差的模；
2. 恒等变形：`z₁(z₃−z₂)+z₃(z₂−z₁)=z₂(z₃−z₁)`（左边=两组对边乘积和，右边=对角线乘积）；
3. 取模 + 三角不等式：`|AC|·|BD| ≤ |AB|·|CD|+|BC|·|AD|`；
4. 取等 ⟺ 两项同向 ⟺ 辐角等式 ⟺ `∠BAD+∠BCD=π`（对角互补 = 四点共圆）。
**信号**：共圆/圆内接、边与对角线的乘积关系、想同时得到等式与不等式版本。
**对比**：经典几何法（对角线上取辅助点 E 构造两组相似三角形，比例相加）直观但只证圆内接情形；复数法先证一般不等式再析取等——**先一般后特殊**是讲义反复出现的顺序偏好。

### M2 切线法（凸函数支撑线）

**内核**：下凸函数 `f` 在 `t₀` 处满足 `f(t) ≥ f(t₀)+f'(t₀)(t−t₀)`（切线在下）。逐项同构的和，用同一条切线逐项放缩再求和。
**流程**：
1. 把目标差式写成 `Σ g(xᵢ)`，找公共等值点 `t₀`（由约束定，如 `Σx=3` 时 `t₀=1`）；
2. 算 `g(t₀), g'(t₀)` 得切线；**切线不等式只在一段区间成立，必须验证区间**（例：`g(x)=1/x²−x²` 在 `x=1` 的切线 `≥ −4+4x` 仅在 `[0,2]` 成立，验法 `x(2−x)≤1`）;
3. 全落区间内 → 求和收工；有变量越界 → 转 M6。
**易错**：不等号方向、切线有效区间、取等只在全体 `xᵢ=t₀`。

### M3 加权均值凑齐次（xyz=1 型）

**内核**：条件 `xyz=1` 允许在任意一边乘 `(xyz)^k`，把不等式两边凑成同次数；再对每个单项用加权 AM-GM，权重由指数决定。
**示例**（`Σx³≥Σx²`，`xyz=1`）：右边乘 `(xyz)^{1/3}` 得目标单项 `x^{7/3}y^{1/3}z^{1/3}`，指数 `(7/3,1/3,1/3)` 归一即权重 `(7/9,1/9,1/9)`：`Σ(7/9·x³+1/9·y³+1/9·z³) ≥ Σ x^{7/3}y^{1/3}z^{1/3}`，三式相加左边系数恰好归一。
**同题备选**：柯西递降（`(Σx³)(Σx)≥(Σx²)²`，降到证 `Σx²≥Σx`）；基本不等式凑 1（`2x³+1≥3x²` 相加，归结为 `Σx²≥3`）；取对数切线（M2）。**一题四解，按条件挑最短的**。
**信号**：`xyz=1` / `a+b+c=常数` 的幂和不等式；次数对不齐时先想"乘条件补齐次"。

### M4 排序不等式正反两用

**内核**：同序和 ≥ 乱序和 ≥ 反序和。正向用来比较不同配对方式的和；反向（"任何乱序和 ≥ 反序和"）用来造下界——倒数序列的反序和恰为 `1+1+…+1`。
**示例**（`Σc³/a³ ≥ Σc²/a²`）：记 `u=c/a, v=b/c, w=a/b`。平方保序 ⇒ `(u²,v²,w²)` 与 `(u,v,w)` 同序。同序和 = `Σu³`；三个"和"（同序+两个乱序）相加 = `(Σu²)(Σu)`，故 `3Σu³ ≥ (Σu²)(Σu)`；再证 `Σu ≥ 3`：`{x,y,z}` 排序后与 `{1/x,1/y,1/z}` 的**反序和恰为 3**，而任意乱序和 ≥ 反序和，`c/a+b/c+a/b` 就是某个乱序和。两步串联即得，全程无 AM-GM。
**信号**：轮换分式、想避开均值不等式、乘积展开天然是"全配对"结构。

### M5 串联不等式（中间桥）+ 无效证明甄别

**内核**：两端直接比不动时，各找一个"好估计"的方向，往同一个中间量挤。示例（`a+b+c=3` 证 `Σ1/a² ≥ Σa²`）：左 ≥ `3/abc`（用 `Σx²≥Σxy` 于倒数），右 ≤ `27/S₁² ≤ 3/abc`（AM-GM 于 `9=S₂+S₁+S₁` + `S₁²≥9abc`），桥成。
**⚠️ 讲义专设反面教材**（错误解法分析）：
- **放缩方向错误**：`(1/x−x)(1/x+x) ≥ 2(1/x−x)` 只有乘数恒正才保号——`1/x−x` 符号不定，`x>1` 时不等号反向；
- **连锁逻辑断裂**：逐项放缩方向不一致时，**求和后大小关系不再成立**（真实值可能比放缩后更小）；
- **结论：中间步骤不恒成立 = 整个证明无效，即使答案巧合正确也是零分。**
**纪律**：每一次放缩写下"依据 + 方向 + 符号检查"；逐项放缩求和前，确认各项方向一致。

### M6 放二丢一 + Jensen 压缩

**内核**：M2 的切线只在有界区间成立。若有变量越界（如 `c>2`）：**丢下它单独处理**，其余变量用凸性（Jensen）合并到均值点，化为单变量函数再单调性收尾。
**示例**（同一题情形二）：`a,b<1` 时 `g` 在 `[0,1)` 下凸 ⇒ `g(a)+g(b) ≥ 2g((a+b)/2)=2g((3−c)/2)`；构造 `F(c)=2g((3−c)/2)+g(c)`，求导后用**四元均值不等式**（`16/(3−c)³+(3−c)+(3−c)+(3−c) ≥ 8`）卡出 `F'(c) ≥ 2−2/c³ > 0`，故 `F(c)>F(2)>0`。
**信号**：切线法/逐项法在一个变量越界时失效；变量个数多、想降维。

### M7 基本不等式嵌套（最低级工具打最难题）

**内核**：`e^t ≥ 1+t` 与伯努利 `(1+y)^r ≥ 1+ry (y≥−1, r≥1)` 两个最基本不等式的**连续嵌套**，可以证出看起来需要隐零点/泰勒高阶的双侧界。
**示例**（`0 ≤ e^{−x}−(1−x/a)^a ≤ (x²/a)e^{−x}`，`a≥1`）：
- 左：`e^{−x/a} ≥ 1−x/a`，取 a 次方（幂函数单调）；
- 右：`e^x(1−x/a)^a = [e^{x/a}(1−x/a)]^a`，内层用 `e^{x/a}≥1+x/a` 得 `(1−x²/a²)`，外层伯努利得 `1−x²/a`。三步嵌套，无需求导。
**方法论**：**工具箱优先级**——高级工具（泰勒、隐零点）之前，先检查两个最基本不等式够不够；讲义的立场是"巧解 = 用最低级工具打通"。
**备选路线（M8 隐零点法）**：令 `f(x)=x²/a+eˣ(1−x/a)^a`，`f'(x)=(x/a)g(x)`，`g` 连续单调 ⇒ 唯一零点 ξ 存在但**不解出**，只定性 `f` 先增后减 ⇒ 最小值在端点 `min{f(0),f(a)} = min{1, a} ≥ 1`。
**隐零点纪律**：只需 `g(0)>0, g(a)<0`（零点存在）+ `g` 单调（唯一）+ 极值点两侧单调性 + **最值归到端点比较**，ξ 全程以符号出场。

### M8 代数问题几何化（海伦/欧拉桥）

**内核**：`xyz ≥ (x+y−z)(x+z−y)(y+z−x)` 型——正数三元组天然联想三角形三边；**"能否构成三角形"是最自然的分类标准**。
**证法一**（平方换元+余弦定理）：`x=a²…` 后若构成三角形，因子化为 `2ab·cos C` 等；非锐角 ⇒ RHS≤0 显然；锐角 ⇒ 归结 `cosAcosBcosC ≤ 1/8`，由 Jensen（`cos` 在 `(0,π/2)` 凹）+ AM-GM 两步。不构成三角形 ⇒ 三个因子一负两正（逐个符号分析），严格成立。
**证法二（几何化彻底版）**：两边乘半周长 p ⇒ 右边 = `8(p−x)(p−y)(p−z) = 8S²`（海伦公式）；左边 `xyz = 4RS`（外接圆半径公式）⇒ 不等式 ⟺ `Rp ≥ 2pr` ⟺ **欧拉不等式 R ≥ 2r**。
**方法论**：看似纯代数的不等式，几何解释后变成经典定理——**"代数问题几何化"与"几何问题代数化（M1）"是一对反向通道**。

### M9 平移齐次化（过定点流水线）

**内核**：圆锥曲线"弦过定点"题有一套机械四步，把聪明题变成计算题。
**流程**（示例：`x²/2+y²=1` 上顶点 M 出发两弦斜率满足 `k₁+k₂+k₁k₂=1`）：
1. **平移**：把定点 M 移到新原点（`y'=y−1`），曲线方程出现一次项；
2. **齐次化**：设弦线 `mx'+ny'=1`，把一次项乘 `(mx'+ny')` 凑成齐二次；
3. **斜率同构**：除以 `x'²`，令 `k=y'/x'`，得 k 的二次方程，韦达定理写出 `k₁+k₂, k₁k₂`；
4. **系数比对**：把斜率条件代入得 m,n 的线性关系，与 `mx'+ny'=1` 比对出定点 `P'(−4,−4)`，平移还原 `P(−4,−3)`。
**信号**：条件是斜率的对称多项式（`k₁+k₂`、`k₁k₂`、`k₁+k₂+λk₁k₂` 等）。

### M10 仿射变换改标准位形

**内核**：伸缩变换保共线性与同直线上的单比（线段比）。把"不在焦点的点"拉伸成焦点，就能用焦点弦结论。
**示例**：`x²/4+y²=1`，M(1,0) 非焦点，条件 `|MA|/|MB|=2`。作 `y'=√3·y`（解 `c'²=4−k²=1` 定 k），M 变右焦点，新椭圆 `e'=1/2`；单比不变仍为 2；用焦点弦比公式 `e|cosθ| = |λ−1|/(λ+1)` 求 `|cosθ'|=2/3` ⇒ `|k'|=√5/2`；还原 `k=±√15/6`。
**信号**：线段比/面积比 + 点位非标准；记住**可用的不变量**（共线、单比）与**会变的量**（斜率要还原换算 `k'=√3k`）。

### M11 秩不等式夹逼 + Vandermonde 非退化（可对角化秩方法）

**工具箱**：Sylvester `r(A)+r(B) ≤ n+r(AB)`（推广到三个）；和秩 `r(A)+r(B) ≥ r(A,B) ≥ r(A+B)`；Frobenius `r(AB)+r(BC) ≤ r(ABC)+r(B)`（分块矩阵初等变换一行证明）。
**二阶模板**：`(A−λ₁E)(A−λ₂E)=O` ⇒ 上界 `r(A')+r(B') ≤ n`（Sylvester）；下界 `n = r(B'−A') ≤ r(A')+r(B')`（和秩，因为 `B'−A'=(λ₁−λ₂)E` 满秩）⇒ 夹逼相等 ⇒ 特征子空间维数和 = n。
**三阶模板**：Frobenius 三式相加得 `r(A'B')+r(A'C')+r(B'C') ≤ n`；下界靠** Vandermonde 型行列式 M₃≠0 ⇒ 存在 (x,y) 使 `xA'B'+yA'C'−B'C' = mE (m≠0)`，再用和秩不等式逐级 `≥ … ≥ r(mE)=n`；夹逼出 `r(A')+r(B')+r(C')=2n`。四阶同理（M₄ 非零 + Frobenius 推 `r(D) ≥ r(ABD)+r(ADC)+r(DCB)`）。
**方法论**：① **上界用秩不等式、下界靠"凑出 mE"**——Vandermonde 非零性 = 线性无关 = 组合非退化，是整座桥的地基；② 可对角化 ⟺ 特征子空间维数和 = n（引理 0.4），秩语言全程不碰特征向量。

### M12 迹的妙用 + 正交三角化（正规阵⇒实对称）

**内核**：`tr(CC') = Σ c_ij²`（Frobenius 范数平方）。矩阵等式两边取迹，交叉项因 `tr(AA')=tr(A'A)` 消掉，剩下"平方和 = 0 ⇒ 矩阵 = 0"。
**流程**（正规 + 实特征值 ⇒ 实对称）：
1. **引理**：分块上三角正规阵 `[A C; 0 B]` ⇒ 比对块得 `AA'+CC'=A'A`，取迹 ⇒ `tr(CC')=0 ⇒ C=0`（一行 vs 暴力逐元素比较）；
2. **正交三角化**：Jordan 形 `A=PJP⁻¹` + QR 分解 `P=QR` ⇒ `A=QDQ'`，D 上三角且**正规性传递**到 D；
3. **归纳剥洋葱**：对 D 逐层用引理，每次消一行非对角元，n−1 步后 D 对角 ⇒ `D=D'` ⇒ `A=A'`。
**方法论**：把"计算性问题"（逐元素比对）转成"结构性问题"（半正定迹为零）；QR 分解在不破坏上三角性的前提下把 P 换成正交阵。

### M13 同时对角化（矩阵不等式降维）

**内核**：A 正定 ⇒ 存在 M 使 `MᵀAM=E`（规范形）；`MᵀBM` 仍实对称 ⇒ 谱定理正交对角化；`P=MQ` 同时合同对角化两者。
**应用**（Minkowski 矩阵不等式 `(ᵐ√)|A+B| ≥ (ᵐ√)|A|+(ᵐ√)|B|`）：行列式全部落在 P 上（`|A|=1/|P|²`、`|B|=∏λᵢ/|P|²`、`|A+B|=∏(1+λᵢ)/|P|²`），约去 `|P|` 后**恰好是初等不等式** `∏(1+λᵢ)^{1/n} ≥ 1+(∏λᵢ)^{1/n}`（初等证明：琴生法 `f=ln(1+eˣ)` 凸；或配凑法 `1/(1+λ)+λ/(1+λ)=1` + 两次 AM-GM）。
**方法论**：**内核复用**——先证标量核，再装进矩阵壳（同时对角化就是那个壳）；反过来做题时，见到矩阵行列式不等式先想"能否合同对角化变成乘积式"。

### M14 复分析定理链（对数留数→辐角→儒歇→FTA）

**链条**：`f'/f` 在 n_k 阶零点留数 `+n_k`、p_k 阶极点留数 `−p_k` ⇒ 对数留数定理 `∮f'/f = N−P`；辐角的几何读法 ⇒ **辐角原理** `N−P = Δ_C arg f / 2π`（像曲线绕原点圈数）；**儒歇定理**：C 上 `|f|>|g|` ⇒ `w=1+g/f` 落在圆心 1 半径 1 的盘内不绕原点 ⇒ `f+g` 与 f 零点数相同（扰动稳定性）；**FTA**：取大圆 R 使首项压制其余项，`P(z)` 与 `a₀zⁿ` 同零点数 ⇒ n 个根。
**方法论**：定理链式推进（每环给下一环当引擎）；儒歇的本质是"**微小扰动不改变零点计数**"，选 `g` 的艺术 = 把多项式拆成"主项 + 小项"。

### M15 刘维尔估值引擎（FTA 第二证法）

**内核**：柯西积分公式积分号下求导 ⇒ `f'(z₀)=1/(2πi)∮f/(z−z₀)²dz`；有界整函数取模 `|f'(z₀)| ≤ M/R → 0` ⇒ 常数。
**FTA 反证模板**：设 p 无零点 ⇒ `1/p` 整函数；`|z|>R` 时 `<1`（首项趋于∞），闭圆上连续有界 ⇒ 全平面有界 ⇒ 常数 ⇒ 与次数矛盾。
**方法论**：估值 + `R→∞` 是复分析的标准引擎；反证时**主动构造倒数** `1/p` 把"零点存在"翻成"有界整函数"。

### M16 有限覆盖→坏点集有限（可积性）

**示例**（合工大：每点极限为 0 ⇒ 可积且积分为 0）：
1. 逐点：`lim_{t→x} f(t)=0` ⇒ 每点有去心邻域使 `|f|<ε`；开覆盖 + **有限覆盖定理** ⇒ `{|f|≥ε}` 只有有限个点；
2. 取 ε=1 得有界性；
3. **可积第三充要条件**：`{|f|≥η/2}` 的 p 个点最多落在 2p 个小区间，取 `‖T‖<ε/2p` 控制坏区间总长，其余区间振幅 ≤ η；
4. 让坏点做分割端点，积分和极限为 0。
**方法论**：**逐点信息 → 全局信息靠紧致性**（有限覆盖）；ε-η 双参数分工（ε 控振幅阈值、η 控坏区间总长）。

### M17 柯西打包 + 导数恒等式（李扬三柯西）

**示例**（`∫f²`、`∫(f')²` 收敛 ⇒ `f→0`）：
- 一次柯西打包：`∫₀^A|ff'| ≤ (∫f²)^{1/2}·(∫(f')²)^{1/2}` 有界 ⇒ `∫|ff'|` 收敛（单调有界）⇒ 绝对收敛蕴含条件收敛（柯西准则，引理 2）；
- **导数恒等式** `ff' = ½[f²]'` ⇒ `∫ff' = ½lim f² − ½f²(0)` ⇒ `lim f²` 存在；
- **引理 1**（反证）：积分收敛 + 极限存在 ⇒ 极限必为 0（否则尾部积分线性爆炸）。
**方法论**：不分别估计 f² 与 (f')²，而是**柯西一次性打包成 |ff'| 的控制**，再借导数恒等式收尾——"打包 + 恒等式转化"双连招；两个引理各司其职，结构分明。

### M18 级数-积分-代换组合拳（巴塞尔 arcsin 模板）

**流程**（ζ(2)=π²/6，无 Fourier 无 Bernoulli 无复分析）：
1. 广义二项式 `(1−x²)^{−1/2}` 展开（`(−1/2 choose n)` 化双阶乘）；
2. **逐项积分**得 `arcsin x = Σ (2n−1)!!/(2n)!! · x^{2n+1}/(2n+1)`；
3. **变量代换 x=sin t** 把级数变成三角积分，**点火公式** `∫₀^{π/2} sin^{2n+1}t dt = (2n)!!/(2n+1)!!` 与系数**完美相消** ⇒ `π²/8 = Σ1/(奇数)²`；
4. **奇偶拆分自举**：`S = π²/8 + S/4` 解一元一次方程 ⇒ `π²/6`。
**方法论**：级数给结构、积分消系数、代换接几何、自举解方程；双阶乘见到点火公式就该想到"消"。

### M19 二次插值估上界（节点=零点+峰值）

**示例**（`π < sinπx/(x(1−x)) ≤ 4`，两端均 sharp）：
- 下界：换元 `u=πx` 归结 `sin u > u−u²/π`（导数分析：`f''` 两零点分三段 / 泰勒+凹性补全）；
- **上界秒杀**：在节点 `0, 1/2, 1`（零点+峰值）作二次 Lagrange 插值 ⇒ `P₂(x)=4x(1−x)` **恰与分母成比例**；余项 `g'''(ξ)/3!·x(x−1/2)(x−1)` 除以分母后 = `4 + (π³/6)cosπξ·(x−1/2)`，`(x−1/2)` 的符号直接判定；`x>1/2` 由对称性 `x↦1−x` 化归。
**方法论**：**插值 vs 泰勒**——泰勒在一点匹配导数，插值在多点匹配函数值；估"整体范围"时插值常给出更紧的界；**节点选择的 art**：让插值多项式与目标分母自然对齐，余项就只剩一个符号因子。
**配套元技巧**："先特殊后一般"：对称函数先证半边，另半边用对称性化归。

### M20 均值不等式链 + 三角恒等式（tan/sin 型）

**示例**（`x∈(0,π/2)`：`tan x + sin x > 2x` 且 `tan x·sin x > x²`）：
- 泰勒路线：`sin x = x−x³/6+o`，`tan x = x+x³/3+o`，相加主项 `2x + x³/6` 显正；
- 均值链路线：`AM > HM` 给 `(tan+sin)/2 > 2/(1/tan+1/sin)`，分母用 `1/tan+1/sin = (1+cos)/sin = cot(x/2)`（半角公式），得 `> 2tan(x/2) > x`（`tan α > α`）；第二问换 `GM > HM` 同一条链，平方收尾。
**方法论**：两问共享同一条化简链——**中间量复用**；`tan α > α` 是三角版"切线下界"，与 M2 同源。

## 3. 元方法论（跨专题的做事方式）

1. **化归优先**：任何题先做"标准化"变形——取对数（幂⟺线性）、平方换元（正数⟺平方）、`u=πx`（区间标准化）、`x=sin t`（代数⟺三角）、平移（定点⟺原点）、仿射（非标位形⟺标准位形）。
2. **一题多解是常态，方法对比是刻意练习**：讲义几乎每个专题都附"方法对比表"（几何法 vs 复数法 / 琴生 vs 均值 / 放缩 vs 隐零点）。做题后问一句"还能怎么死"，比多做三道新题涨功力。
3. **无效证明甄别（竞赛纪律）**：放缩必须检查"乘数符号"；逐项放缩求和前确认方向一致；中间步骤不恒成立 = 全盘无效，结论巧合正确也是零分。
4. **取等条件永远单独验证**，并且用取等条件反推"哪些步骤必须收紧"（讲义每张结论框都标等号成立条件）。
5. **工具箱优先级**：`e^t≥1+t`、伯努利、排序、柯西这些"最低级武器"够用就不上泰勒/隐零点/复分析；但要知道每种高级工具的"触发信号"（M8 的 ξ、M14 的绕圈数）。
6. **等式⟸⟹不等式升级链**：代数恒等式 → 取模/取绝对值 → 三角不等式 → 不等式（M1）；标量核 → 合同/相似变换 → 矩阵不等式（M13）。**先证一般，再析取等**。
7. **计算机代数系统当验证器**：四阶 Vandermonde 恒等式用 MATLAB/Mathematica 展开比对 + "三次多项式有四个根则为恒等式"的根计数论证（降次验证法）。CAS 验证不等于证明，但能指路 + 防算错。
